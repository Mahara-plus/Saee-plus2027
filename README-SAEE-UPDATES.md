# Saee Plus — تحديثات الواجهة

## التعديلات
- أصبحت نافذة تسجيل الدخول/إنشاء الحساب تظهر تلقائيًا عند فتح الموقع إذا لم توجد جلسة محلية صحيحة.
- أزيل خيار متابعة التصفح بدون حساب، ولا يمكن إغلاق نافذة الحساب قبل تسجيل الدخول.
- حدّثت ملاحظة الحساب لتوضيح أن الحسابات ما زالت محلية في هذا الإصدار.
- أضيف التحقق من معرض المشاريع (حتى 10 صور) إلى التحقق الخلفي في `lib/content-validation.js`.
- حدّث `lib/cms.ts` لرفع صور معرض المشروع إلى تخزين الصور (R2) بدل إرسال صور Base64 كبيرة مباشرة داخل قاعدة البيانات.

## تنبيه مهم بخصوص التزامن بين الأجهزة
هذه التعديلات وحدها لا تُفعّل المزامنة في موقع GitHub Pages المنشور؛ الملف `public/store.js` في المشروع ما زال يستخدم التخزين المحلي (`remote = false`). كما أن مسار API في مشروع Next/Vinext يعتمد حاليًا على مصادقة ChatGPT. لذلك يلزم تعديل/نشر Cloudflare Worker الفعلي وربط `public/store.js` به مع جلسات إدارة آمنة حتى تظهر تعديلات الإدارة على كل الأجهزة. لم أغيّر `remote` إلى `true` بشكل عشوائي حتى لا يتعطل الموقع أو تُفقد التعديلات.

## الملفات التي تغيرت

## تحديث: النشر المباشر من الأدمن + زر «تم الخصم»
- `public/store.js`: أضيفت `loginAdmin` و`logoutAdmin` (كانت لوحة الأدمن تستدعيهما وغير موجودتين)، وجلسة الأدمن تُرسل أيضًا كـ Bearer token حتى تعمل على Safari/الجوال.
- رفع الصور: الصور تُرفع تلقائيًا إلى `/api/media` بدل تخزينها Base64 داخل المحتوى، فلا يفشل الحفظ بسبب الحجم.
- `cloudflare/worker.js`: أضيف `/api/media` (رفع للأدمن، وقراءة عامة)، ودعم `Authorization: Bearer`. **يجب إعادة نشر الـ Worker.**
- `public/app.js`: نافذة تفاصيل الخصومات تعرض زر «تم الخصم» تلقائيًا لكل خصم (قديم أو جديد).
- `public/discounts.js`: إصلاح حلقة لا نهائية كانت تجمّد الصفحة عند وجود الزر، وربط الاستخدام بإيميل الحساب.


## إدارة مشاريع الطلبة
- يستطيع المستخدم إرسال مشروعه، ومتابعة حالته من قسم «مشاريعي».
- يستطيع صاحب المشروع تعديل بيانات مشروعه أو حذفه.
- تعديل المستخدم لمشروع معتمد يعيده تلقائيًا إلى حالة «بانتظار المراجعة» حتى لا تُنشر التعديلات قبل موافقة الإدارة.
- تستطيع الإدارة الموافقة والنشر أو الرفض أو إعادة المشروع للانتظار، كما تستطيع تعديل جميع بيانات المشروع أو حذفه.
- تم توسيع واجهة الإدارة لتعرض إجراءات التعديل والحذف لكل مشروع.


## حماية إحصائيات الموقع
- لم يتم تعديل منطق الإحصائيات الموجود في واجهة الموقع.
- تمت إضافة/تأكيد المسار `GET /api/statistics` في Cloudflare Worker ليعيد عدد الحسابات المسجلة فعليًا من جدول `users` باستخدام `COUNT(*)`.
- هذا المسار مستقل عن جدول `vocational_projects`؛ لذلك إضافة المشاريع أو تعديلها أو حذفها أو الموافقة عليها لا تزيد أو تنقص عدد المستخدمين.
- يجب نشر نسخة `cloudflare/worker.js` حتى يعمل مسار الإحصائيات من نفس Worker المستخدم في الموقع.
