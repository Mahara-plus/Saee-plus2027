# تحديث نموذج إضافة المشاريع ومراجعتها

## ما الذي تغيّر؟
- نموذج «شارك مشروعك» في النافذة الظاهرة من الصفحة الرئيسية أصبح يتضمن رابط صورة المشروع ورابط إنستغرام ورابط فيسبوك ورقم التواصل.
- تُحفظ المشاريع الجديدة بحالة `pending` ولا تظهر في قائمة المشاريع العامة حتى اعتمادها.
- من لوحة الإدارة > إدارة المحتوى > المشاريع تظهر تفاصيل التواصل وحالة المشروع، مع زري «قبول ونشر» و«رفض» بالإضافة إلى التعديل والحذف.
- عند قبول المشروع تتحول حالته إلى `approved` ويظهر للعامة. وعند رفضه يبقى مخفيًا.
- تعديل مشروع موجود من لوحة الإدارة يحافظ على حالة مراجعته.

## الملفات المعدلة
- `public/app.js`
- `public/admin.js`

## النشر
ارفع الملفين إلى المسارين نفسيهما في مستودع GitHub ثم انتظر اكتمال النشر. لا يوجد تعديل مطلوب على `cloudflare/worker.js` أو قاعدة D1 لهذا التغيير؛ التخزين يتم عبر آلية SiteStore الموجودة في المشروع.

## الإحصائيات
لم يتم تعديل كود الإحصائيات أو واجهة API الخاصة بها.
