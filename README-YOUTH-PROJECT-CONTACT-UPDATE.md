# تحديث بيانات التواصل لمشاريع الشباب

تمت إضافة الحقول الاختيارية التالية إلى نموذج مشروع الشباب:
- رابط صورة المشروع (الحقل الموجود سابقاً).
- رابط إنستغرام.
- رابط فيسبوك.
- رقم هاتف للتواصل.
- وسيلة تواصل إضافية.

يمكن لصاحب المشروع تعديل جميع هذه الحقول أو حذف مشروعه. ويمكن للإدارة تعديل الحقول نفسها أو حذف المشروع من لوحة الإدارة. تظهر روابط التواصل ورقم الهاتف في بطاقة المشروع المعتمد.

## النشر
1. ارفع ملفات الموقع المحدّثة إلى GitHub، وبالأخص `public/vocational.html` و`public/admin.js`.
2. انشر `cloudflare/worker.js` المحدّث على Cloudflare Workers.
3. استخدم قاعدة D1 الحالية نفسها، ولا تنشئ قاعدة جديدة.

يتضمن Worker ترقية متوافقة تضيف الأعمدة الناقصة تلقائياً عند استخدام واجهة المشاريع. يوجد أيضاً ملف migration اختياري للتوثيق/التطبيق اليدوي إذا كانت طريقة النشر لديكم تعتمد migrations؛ لا تطبّقه إذا كانت الأعمدة قد أُضيفت بالفعل.

## الإحصائيات
لم يتم تعديل مسار `/api/statistics` أو استعلام عدّ المستخدمين أو جدول `users`. عمليات مشاريع الشباب لا تزيد أو تنقص عدد المستخدمين.
